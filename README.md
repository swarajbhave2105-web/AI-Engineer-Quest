# AI-Engineer-Quest V1.01

A mobile-first, Duolingo-style 48-hour learning quest for complete beginners becoming front-end AI engineers.

## Stack
Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lucide React, Zustand and LocalStorage persistence.

## Curriculum
24 modules across four phases, each designed as a two-hour learning block. Project milestones are Modules 6, 12, 18 and 24.

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production
```bash
npm run build
```

The app uses a static Next.js export and is ready for Vercel deployment.
